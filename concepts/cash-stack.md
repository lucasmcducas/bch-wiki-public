# Cash Stack

**Source**: https://cashstack.info

---

The Cash Stack is a layered technology architecture built on top of Bitcoin Cash. It defines how different protocols and technologies stack together to form a complete decentralized application platform.

## Known layers

- **BCH Network** — Base layer: blockchain, transactions, consensus
- **Token Layer** — CashTokens (modern, native token protocol). **SLP is deprecated/discontinued.**
- **File Storage** — IPFS integration, decentralized file storage
- **Application Layer** — PSF APIs, CashScript smart contracts
