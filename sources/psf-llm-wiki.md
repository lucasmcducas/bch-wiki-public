# PSF LLM Wiki

**Source**: https://github.com/FullStack-Agents/psf-llm-wiki

**Accessed**: 2026-07-01

**Latest release**: v3.0.1 (April 2026)

---

An LLM Wiki based on Andrej Karpathy's concept, applied to Bitcoin Cash (BCH), the Permissionless Software Foundation (PSF), and the Cash Stack.

## Structure

- `wiki/` — 120+ Markdown pages covering BCH concepts, maintained by an AI agent
- `wiki/index.md` — Table of contents
- `wiki/log.md` — Append-only operation log
- `processed/` — Immutable source documents
- `AGENTS.md` — Instructions for AI agents on how to maintain the wiki

## Topics covered

The wiki covers: BCH network, transactions (anatomy, validation, signing), addresses (cashaddr, base58check), wallets (digital wallets, cold storage, minimal SLP wallet), SLP tokens (Simple Ledger Protocol, fungible tokens, NFT1, genesis, mint, send), CashTokens (spec, alternatives, rationale, stakeholders), PSF (Permissionless Software Foundation, PSF BCH API, PSF token), mining, blockchain structure, UTXO model, mempool, IPFS integration, decentralized file storage, CashScript language, BCHN full node, Fulcrum indexer, Cauldron, and more.
